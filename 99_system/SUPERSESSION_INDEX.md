# Supersession Index

A decision in an archived file is not current. If it appears here, it is dead.
Do not re-apply it, and do not re-derive it from the old text.

## Why this file exists

An archived document keeps arguing its case forever. A reader who finds it has no
way to know the decision was reversed unless something says so. That is how a
settled question gets re-opened months later, and how a fixed bug gets
reintroduced. One row here prevents both.

See also the frontmatter status check in `CLAUDE.md`: a body with
`meta_status: superseded` is history, not instruction.
