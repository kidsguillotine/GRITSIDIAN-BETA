# Obsidian Hotkeys Reference

On macOS use Cmd where this table says Ctrl.

## The five you will use constantly

| Keys | Action |
|---|---|
| `Ctrl P` | Command palette. Every command is in here. Start with this one. |
| `Ctrl O` | Quick switcher. Jump to a note by typing its name. |
| `Ctrl Shift F` | Search the whole vault. |
| `Ctrl N` | New note. |
| `Ctrl E` | Switch between edit view and reading view. |

## Navigation

| Keys | Action |
|---|---|
| `Ctrl G` | Graph view. See how notes connect. |
| `Alt Left` | Go back. |
| `Alt Right` | Go forward. |
| `Ctrl Click` a link | Open the linked note in a new pane. |
| `Ctrl Shift T` | Reopen the note you just closed. |

## Writing

| Keys | Action |
|---|---|
| `[[` | Start a wikilink. A list of notes appears as you type. |
| `Ctrl B` | Bold. |
| `Ctrl I` | Italic. |
| `Ctrl K` | Insert a web link. |
| `Ctrl /` | Comment out the line. |
| `Ctrl Enter` | Tick or untick a checkbox. |

## Panes and layout

| Keys | Action |
|---|---|
| `Ctrl \` | Split the pane to the right. |
| `Ctrl W` | Close the pane. |
| `Ctrl Shift E` | Show or hide the file list. |
| `Ctrl ,` | Settings. |

## Useful commands with no default key

Open the command palette (`Ctrl P`) and type the name. Assign a key in
Settings, then Hotkeys, if you use one often.

- `Daily notes: Open today's daily note`
- `Templater: Insert template`
- `Dataview: Rebuild current view`
- `Linter: Lint the current file`
- `Smart Connections: Open view` (suggests related notes)

## Setting your own

Settings, then Hotkeys. Search the command. Click the plus icon. Press the keys.
If a key is already used, Obsidian shows the conflict. Record any custom key in
the table below so you do not forget it.
