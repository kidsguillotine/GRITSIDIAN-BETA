# attachments

Images, PDFs, and other media pasted or dragged into notes land here.

Set this in Obsidian: Settings, then Files and links, then "Default location for
new attachments", then choose "In the folder specified below" and enter
`attachments`. Without this, Obsidian scatters images next to every note.

Embed an image with `![[picture.png]]`. Media embeds keep their file extension.
Wikilinks to notes do not. See `wiki/Wikilinks`.
