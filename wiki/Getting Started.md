# Getting Started

This page is for people who use Word, Excel, and the normal Windows file system.
You do not need to be a programmer. Read each sentence in order.

## What this is

Obsidian is a free program. It shows a folder of text files as linked notes.
This folder is called a **vault**.

Claudian is an AI helper. It works inside your vault. It follows a set of
written rules. The rules keep your files safe.

A **note** is one text file. It ends in `.md`. You can open it in Word or
Notepad. It is plain text with simple marks for bold and headings.

## What the helper does for you

- It sorts new notes into the correct folder.
- It links related notes together.
- It saves a full copy of your vault often. See [[Git Backup]].
- It keeps private files out of that copy. See [[Sensitivity and Security]].

## What you must do first

1. Install Obsidian. Get it from the Obsidian website.
2. Copy this whole folder to your computer.
3. Open the folder in Obsidian as a vault.
4. Install the add-ons. See [[Plugins]].
5. Run the setup step. See `SETUP.md` in the top folder. It fixes the file paths
   for your computer.

On Windows, or from a USB drive, read [[Windows and Flash Drive]] first.

## The three ideas to remember

1. Your notes are just files. You still own them. You can open them without this
   tool.
2. The helper asks before it changes anything important. It does not act alone.
   See [[The Rules (Simple English)]].
3. A backup runs on its own. If your computer breaks, your notes are safe. See
   [[Git Backup]].
