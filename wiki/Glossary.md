# Glossary

For people who use Word, Excel, and folders, but not developer tools. One line
each.

| Word | Plain meaning |
|---|---|
| Vault | A folder of notes that Obsidian opens as one linked notebook. |
| Note | One text file, ending in `.md`. Opens in Notepad or Word. |
| Markdown (`.md`) | Plain text with simple marks for bold, lists, and headings. |
| Obsidian | The free program that shows a vault as linked notes. |
| Plugin | An add-on that gives Obsidian a new feature. See [[Plugins]]. |
| AI helper / agent | A program that reads your request and does note tasks under rules. |
| CLAUDE.md | The file that holds the AI's rules. |
| Wikilink | A link between notes, written `[[note name]]`. See [[Wikilinks]]. |
| Frontmatter / Properties | A small data block at the top of a note. See [[Frontmatter and Structure]]. |
| meta_status | A frontmatter field that says if a note is live or old. |
| Git | A program that saves full snapshots of your folder. See [[Git Backup]]. |
| Commit | One saved snapshot in git. |
| Push | Sending your commits to a copy on another computer. |
| Remote | The other-computer copy of your snapshots (often a private online repo). |
| Repository (repo) | A folder that git is tracking. |
| Hook | A small script git or the AI runs on its own at a set moment. |
| Pre-commit hook | A safety check that runs each time you make a commit. See [[Sensitivity and Security]]. |
| `.gitignore` | A list of files git must not save. |
| `.env` | A small settings file for secrets. Git ignores it. |
| Sensitive store | A folder outside git where private files are kept. |
| Security fire | An open security problem the AI must handle first. |
| Dry run | A preview of a change that does not do the change yet. |
| Script | A small program, ending in `.sh` (shell) or `.py` (Python). |
| Bash | The program that runs `.sh` scripts. On Windows, Git Bash provides it. |
| Python | A programming language some scripts use. |
| Terminal / command line | A window where you type commands instead of clicking. |
| MCP | Model Context Protocol. A shared way for AI tools to call programs. |
| REST API | A local door that lets programs read and write your notes. |
| MOC | Map of Content. An index note that links many notes on one topic. |
| WSL | Windows Subsystem for Linux. Runs Linux inside Windows. |
| exFAT | A USB drive format that works on Windows, Mac, and Linux. |
| ASD-STE100 | Simplified Technical English. A plain writing style with short sentences. |
