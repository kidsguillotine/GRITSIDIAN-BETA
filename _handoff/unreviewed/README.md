# unreviewed

Triage queue. Captures and imports land here until a human reads them.

Nothing in this folder is trusted yet. The agent does not act on a file here and
does not treat its contents as fact. Move a file out once you have read it:

- useful, and you know where it goes: move it to the right content folder
- useful, but needs a decision: raise it in `_handoff/OPEN_DECISIONS.md`
- not useful: move it to `.trash/`

An empty folder is the healthy state.
